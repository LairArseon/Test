# One Clear View

A visual, independent introduction to the operational advantages of Microsoft Dynamics 365 Business Central. This project is not affiliated with or endorsed by Microsoft.

## Run locally

Requires Node.js 20 or newer.

```bash
npm run dev
```

Open `http://localhost:3000` in a browser. Use `npm start` for a non-watch server.

## Structure

- `server.js` - dependency-free Node HTTP server for static files.
- `public/index.html` - semantic single-page content.
- `public/styles.css` - responsive visual system.
- `public/app.js` - mobile navigation and dashboard signal interaction.

The page uses a remote, appropriately licensed Unsplash image for its hero photograph and Lucide icons via CDN.# Test
